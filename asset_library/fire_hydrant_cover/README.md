# Hydrant covers

## Overview

A rectangular ductile-iron cover for a single-outlet hydrant.

## Usage

```sh
blender -b --python asset_library/fire_hydrant_cover/scripts/build_fire_hydrant_cover.py
```

## Specifications and placement

- Nominal lid: 500 × 400 mm.
- Outer frame: 560 × 460 mm.
- Top surface: approximately Z = 0; the body and frame extend below grade.
- Modeled diagonal grid, fire-service emblem, cast lettering, opening recesses, and keyhole.
